================================================================================
                        INSTALLATION INSTRUCTIONS
================================================================================

1. INSTALL EA:
   - Copy EA_TradingBot.mq4 to MT4/MQL4/Experts/ folder
   - Compile in MetaEditor (F7) or restart MT4

2. CONFIGURE PARAMETERS:
   For multiple EAs on same account:
   
   EA #1 (XAUUSD):
   - MagicNumber = 10101
   - Symbol = "XAUUSD"
   - StrategyToRun = 0 (Turtle)
   
   EA #2 (EURUSD):
   - MagicNumber = 10201
   - Symbol = "EURUSD"
   - StrategyToRun = 1 (MA Cross)
   
   EA #3 (GBPUSD):
   - MagicNumber = 10301
   - Symbol = "GBPUSD"
   - StrategyToRun = 2 (Mean Reversion)
   
   IMPORTANT: Same global variable prefixes for all EAs!

3. SETUP EMAIL (OPTIONAL):
   - MT4 → Tools → Options → Email
   - Enable and configure SMTP
   - Test connection

4. ATTACH TO CHARTS:
   - Open H1 chart for each symbol
   - Drag EA from Navigator to chart
   - Check "Allow live trading"
   - Click OK

5. VERIFY:
   - Smiley icon visible on charts
   - Check Experts tab for startup messages
   - Monitor Global Variables (Tools → Global Variables)

================================================================================
                          TROUBLESHOOTING
================================================================================

"Trade slot is held by EA with MagicNumber=XXXXX"
  → Normal behavior. Another EA has active trade not at BE.
  → Wait for trade to reach break-even.

"Cannot open new trade: Not all account trades are at break-even"
  → Check which trades are not at BE
  → Wait or close manually if needed

"Global daily stop is active - trading blocked"
  → 5% daily loss was reached
  → Trading automatically resumes next day
  → Review what went wrong

No break-even movement
  → Check BreakEvenPips parameter (default: 50)
  → Verify trade has enough profit
  → Check BE_ATR_Multiplier setting
